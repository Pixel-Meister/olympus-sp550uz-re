Reverse Engineer the Olympus SP 55OUZ

The goal of this project is to get the firmware extracted from the camera, which is attached to the computer at
(from lsusb)
Bus 005 Device 008: ID 07b4:0109 Olympus Optical Co., Ltd C-370Z/C-500Z/D-535Z/X-450

The goal is to reverse engineer the camera's firmware architecture, decode the TruePic III memory map, analyze the display and power management pipelines, and produce comprehensive reverse engineering documentation and decompiler tooling.

Let me know if you have any questions or if you need me to do anything. Good luck!
